# EL-Gebaly Attendance — النسخة الأولى

نسخة MVP لتطبيق Android للحضور والانصراف.

## الموجود
- مستخدمون متعددون.
- سعر ساعة لكل مستخدم.
- تحقق ببصمة/المصادقة الحيوية للهاتف قبل الحضور والانصراف.
- تسجيل التاريخ والوقت محليًا.
- حساب ساعات العمل والمستحقات.
- سجل المستخدم.
- إنشاء PDF ومشاركته.

## ملاحظة
هذه ملفات المشروع المصدرية وليست APK مبنيًا؛ بيئة المحادثة الحالية لا تحتوي Android SDK/Gradle لبناء APK مباشرة.
